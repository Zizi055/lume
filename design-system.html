Анимация

Единая кривая плавности на весь сайт и два паттерна появления при скролле.

Easing
--ease: cubic-bezier(.22, 1, .36, 1)

Используется во всех transition — кнопки, ссылки, hover-состояния карточек, скролл-парал­лакс.

.reveal / .reveal-stagger

Секции появляются снизу (translateY 24–32px → 0) через IntersectionObserver. .reveal-stagger дополнительно распределяет задержку по дочерним элементам (0.02s → 0.37s) для эффекта очереди.
